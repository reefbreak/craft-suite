# ArtCraft brand marks: removed from this build

This copy of VectorCraft is a modified build in the Gesso craft-suite. It is not an official
VectorCraft or ArtCraft release.

[`LICENSE-brand.txt`](LICENSE-brand.txt) requires anyone who distributes a modified version of
VectorCraft to remove the ArtCraft Marks (the ArtCraft name used as a brand, the wordmark and the
logos) and not to present it as an ArtCraft product. So the wordmark and mark files that upstream
keeps in this folder (`artcraft-logo*.png/.svg` and `artcraft-mark*.png/.svg`) have been deleted.
The app itself never drew them: its title-bar brand mark is the VectorCraft app icon (original
artwork in `assets/app-icon/`, MIT OR Apache-2.0), which is not an ArtCraft Mark and stays. Only the
README and attribution changed. The README carries no logo images.

The ArtCraft name still appears in plain text where the licence allows it: to say that this build is
based on VectorCraft by the ArtCraft team, and to label links to the upstream project (its Discord
and getartcraft.com). `LICENSE-brand.txt` is kept unchanged for reference.

Do not add the mark files back to this build.
