# ArtCraft brand marks: removed from this build

This copy of EffectCraft is a modified build in the Gesso craft-suite. It is not an official
EffectCraft or ArtCraft release.

[`LICENSE-brand.txt`](LICENSE-brand.txt) requires anyone who distributes a modified version of
EffectCraft to remove the ArtCraft Marks (the ArtCraft name used as a brand, the wordmark and the
logos) and not to present it as an ArtCraft product. So the wordmark and mark files that upstream
keeps in this folder (`artcraft-logo*.png/.svg`, `artcraft-mark*.png/.svg` and their `.attribution`
sidecars) have been deleted. The app no longer draws the mark: the Tools bar shows the name
"EffectCraft" in plain text where the mark was (it still opens About), and the About dialog shows
the name and version without a logo. The README carries no logo images.

The ArtCraft name still appears in plain text where the licence allows it: to say that this build is
based on EffectCraft by the ArtCraft team, and to label links to the upstream project (its Discord
and getartcraft.com). `LICENSE-brand.txt` is kept unchanged for reference.

Do not add the mark files back to this build.
