# ArtCraft marks: removed from this build

This copy of PhotoCraft is a modified build, part of the Gesso craft-suite. It is not an official
PhotoCraft or ArtCraft release.

The ArtCraft name, wordmark and mark (the "ArtCraft Marks") are trademarks of the ArtCraft Team and
are not open source. [`LICENSE-brand.txt`](LICENSE-brand.txt) requires a distributed modified
version to remove them and not to present itself as an ArtCraft product, so the logo and mark files
that used to live in this directory (`artcraft-logo*.svg/png`, `artcraft-mark*.svg/png`) were
deleted, and nothing in this build draws, embeds or links to them. `LICENSE-brand.txt` is kept
unchanged for reference.

What remains is plain text: this build is based on PhotoCraft by the ArtCraft team, and some links
(the ArtCraft Discord, getartcraft.com) point to that upstream project. The PhotoCraft app icon in
`assets/app-icon/` is not an ArtCraft Mark; it is original artwork licensed MIT OR Apache-2.0 like
the rest of the code (see its `LICENSE.txt`).
