# ArtCraft brand marks: removed from this build

This copy of FilmCraft is a modified build in the Gesso craft-suite (it adds File ▸ Send to Gesso).
It is not an official FilmCraft or ArtCraft release.

[`LICENSE-brand.txt`](LICENSE-brand.txt) requires anyone who distributes a modified version of
FilmCraft to remove the ArtCraft Marks (the ArtCraft name, wordmark and logos) and not to present it
as an ArtCraft product. So the wordmark and mark files that upstream keeps in this folder
(`artcraft-logo*.png/.svg`, `artcraft-mark*.png/.svg` and their `.attribution` sidecars) have been
deleted, and the app no longer draws them: the About dialog and the Home screen show plain text
instead, and the README carries no logo images.

The ArtCraft name still appears in plain text where the licence allows it: to say that this build is
based on FilmCraft by the ArtCraft team, and to label links to the upstream project (its Discord and
getartcraft.com). `LICENSE-brand.txt` is kept unchanged for reference.

Do not add the mark files back to this build.
