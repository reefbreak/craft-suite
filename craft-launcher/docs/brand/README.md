# ArtCraft brand marks: removed from this build

This copy of the launcher is **Gesso Launcher**, a modified build of ArtCraft Launcher in the Gesso
craft-suite. It is not an official ArtCraft Launcher or ArtCraft release.

[`LICENSE-brand.txt`](LICENSE-brand.txt) requires anyone who distributes a modified version of
ArtCraft Launcher to remove the ArtCraft Marks (the ArtCraft name, wordmark and logos) and not to
present it as an ArtCraft product. So the wordmark and mark files that upstream keeps in this
folder (`artcraft-logo*.png/.svg`, `artcraft-mark*.png/.svg`, including the `-64` and `-black-44`
tray renders) have been deleted, and the app no longer draws them: the header shows the name
"Gesso Launcher" in plain text, and the app, tray, installer and DMG icons are the Gesso mark
(see [`assets/app-icon/README.md`](../../assets/app-icon/README.md)).

The ArtCraft name still appears in plain text where the licence allows it: to say that this build
is based on ArtCraft Launcher by the ArtCraft team, and to label links to the upstream project and
its services (getartcraft.com, its GitHub, Discord and social accounts, and the ArtCraft API the
launcher reads release information from). `LICENSE-brand.txt` is kept unchanged for reference.

Do not add the mark files back to this build.
